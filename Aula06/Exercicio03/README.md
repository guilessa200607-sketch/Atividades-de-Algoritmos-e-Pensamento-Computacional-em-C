# Aula 06 - Exercício 03

## Objetivo

Praticar o **laço `while`** com condição de parada e o operador de resto (`%`).

## Descrição da solução

O programa lê números inteiros até o usuário digitar 0 e soma apenas os números ímpares (os que têm resto diferente de 0 na divisão por 2). Ao final exibe a soma dos ímpares.

## Como compilar e executar

```bash
gcc main.c -o programa -Wall -Wextra
./programa
```

## Observações importantes

- O 0 encerra a leitura e não entra na soma.
- Números negativos ímpares também são somados.
