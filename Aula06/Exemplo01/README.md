# Aula 06 - Exemplo 01

## Objetivo

Praticar o **laço `for`** em C.

## Descrição da solução

O programa lê um número inteiro e exibe a tabuada dele, de 0 a 10, usando um laço `for`. Ao terminar, mostra também o valor final da variável `i`, que é 11 (o valor que faz a condição do laço deixar de ser verdadeira).

## Como compilar e executar

```bash
gcc main.c -o programa -Wall -Wextra
./programa
```

## Observações importantes

- A mensagem final mostra que, depois do laço, `i` vale 11 e não 10.
