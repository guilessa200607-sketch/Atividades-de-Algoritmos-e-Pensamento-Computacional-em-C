# Aula 06 - Exercício 06

## Objetivo

Praticar o **laço `do...while`** com **menu de opções** e acumulação de valores.

## Descrição da solução

O programa mostra o cardápio da Cafeteria Analia (X-Burger, Batata frita, Suco e Pudim) e soma o preço de cada item escolhido, exibindo o subtotal a cada pedido. A opção 5 (ou 0) encerra o menu e o programa mostra o total do pedido.

## Como compilar e executar

```bash
gcc main.c -o programa -Wall -Wextra
./programa
```

## Observações importantes

- Opções fora de 1 a 5 são ignoradas e o menu é exibido de novo.
