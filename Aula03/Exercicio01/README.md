# Aula 03 - Exercício 01

## Objetivo

Praticar **entrada de dados** (`scanf`), variáveis inteiras e soma.

## Descrição da solução

O programa lê a quantidade de produtos recebida pela manhã e a recebida à tarde e exibe o total de produtos recebidos no dia.

## Como compilar e executar

```bash
gcc main.c -o programa -Wall -Wextra
./programa
```

## Observações importantes

- Os valores devem ser números inteiros.
