# Aula 03 - Exercício 08

## Objetivo

Praticar **média ponderada** com números reais.

## Descrição da solução

O programa lê três notas e calcula a média ponderada com pesos 1, 2 e 4: `(nota1*1 + nota2*2 + nota3*4) / (1 + 2 + 4)`.

## Como compilar e executar

```bash
gcc main.c -o programa -Wall -Wextra
./programa
```

## Observações importantes

- Os pesos estão fixos no código.
- As mensagens que pediam sempre "a primeira nota" foram corrigidas para primeira, segunda e terceira.
