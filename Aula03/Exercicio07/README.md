# Aula 03 - Exercício 07

## Objetivo

Praticar **fórmulas** com números reais: média aritmética.

## Descrição da solução

O programa lê quatro valores reais e calcula e exibe a média aritmética deles.

## Como compilar e executar

```bash
gcc main.c -o programa -Wall -Wextra
./programa
```

## Observações importantes

- Os valores usam **ponto** como separador decimal na digitação.
