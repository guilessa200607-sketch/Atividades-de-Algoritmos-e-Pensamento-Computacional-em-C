# Aula 03 - Exercício 02

## Objetivo

Praticar **operações aritméticas** com números inteiros.

## Descrição da solução

O programa lê a hora e os minutos atuais e calcula quantos minutos já se passaram desde o início do dia (`hora * 60 + minutos`).

## Como compilar e executar

```bash
gcc main.c -o programa -Wall -Wextra
./programa
```

## Observações importantes

- O programa não valida se a hora está entre 0 e 23 nem se os minutos estão entre 0 e 59.
