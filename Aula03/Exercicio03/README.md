# Aula 03 - Exercício 03

## Objetivo

Praticar as **quatro operações** básicas com números inteiros (soma, subtração e multiplicação).

## Descrição da solução

O programa lê dois números inteiros e exibe a soma, a subtração (primeiro menos segundo) e a multiplicação entre eles.

## Como compilar e executar

```bash
gcc main.c -o programa -Wall -Wextra
./programa
```

## Observações importantes

- A divisão não faz parte deste exercício.
