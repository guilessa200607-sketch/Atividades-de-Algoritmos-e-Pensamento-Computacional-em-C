# Aula 03 - Exercício 05

## Objetivo

Praticar **fórmulas** com números reais.

## Descrição da solução

O programa lê o peso (kg) e a altura (m) de uma pessoa e calcula o Índice de Massa Corporal (IMC) pela fórmula `peso / (altura * altura)`, exibindo o resultado com duas casas decimais.

## Como compilar e executar

```bash
gcc main.c -o programa -Wall -Wextra
./programa
```

## Observações importantes

- A altura deve ser digitada em metros, com ponto decimal (por exemplo, `1.75`).
