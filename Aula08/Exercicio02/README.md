# Aula 08 - Exercício 02

## Objetivo

Praticar **vetores** com cálculo de média e contagem de elementos acima dela.

## Descrição da solução

O programa lê 8 valores reais e os soma durante a leitura. Calcula a média e, em um segundo laço, conta quantos valores são maiores que a média, exibindo a média e essa quantidade.

## Como compilar e executar

```bash
gcc main.c -o programa -Wall -Wextra
./programa
```

## Observações importantes

- Valores iguais à média **não** são contados como acima da média.
