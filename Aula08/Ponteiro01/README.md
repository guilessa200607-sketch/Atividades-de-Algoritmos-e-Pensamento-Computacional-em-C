# Aula 08 - Ponteiro 01

## Objetivo

Praticar **matrizes** com total por linha (atividade da aula sobre ponteiros).

## Descrição da solução

O programa lê, em uma matriz 3 x 4, a quantidade vendida de 3 produtos em 4 dias e exibe o total de cada produto.

## Como compilar e executar

```bash
gcc main.c -o programa -Wall -Wextra
./programa
```

## Observações importantes

- Esta versão acessa a matriz por índices (`produtos[i][j]`), sem usar ponteiros explicitamente.
