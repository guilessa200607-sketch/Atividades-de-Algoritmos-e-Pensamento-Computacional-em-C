# Aula 08 - Exercício 06

## Objetivo

Praticar **vetores** com média, maior valor, menor valor e contagem.

## Descrição da solução

O programa lê a temperatura de 7 dias e calcula a média, a maior temperatura, a menor temperatura e a quantidade de dias com temperatura acima da média, exibindo todos esses resultados em °C.

## Como compilar e executar

```bash
gcc main.c -o programa -Wall -Wextra
./programa
```

## Observações importantes

- Os acentos e o símbolo `°C` dependem do terminal estar configurado para UTF-8 (no Windows, use `chcp 65001` antes de executar).
