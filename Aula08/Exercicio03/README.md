# Aula 08 - Exercício 03

## Objetivo

Praticar **vetores** com média, maior valor e contagem de elementos abaixo da média.

## Descrição da solução

O programa lê o salário de 6 funcionários e calcula a média salarial. Em um segundo laço, encontra o maior salário e conta quantos salários estão abaixo da média. Ao final, exibe a média, o maior salário e a quantidade de salários abaixo da média.

## Como compilar e executar

```bash
gcc main.c -o programa -Wall -Wextra
./programa
```

## Observações importantes

- Salários iguais à média **não** são contados como abaixo da média.
