# Aula 08 - Exercício 05

## Objetivo

Praticar **matrizes** com média por linha e busca do maior valor.

## Descrição da solução

O programa usa uma matriz 3 x 4 (3 estudantes e 4 avaliações) para guardar as notas. Calcula e exibe a média de cada estudante e, ao final, informa qual estudante teve a maior média e o valor dessa média.

## Como compilar e executar

```bash
gcc main.c -o programa -Wall -Wextra
./programa
```

## Observações importantes

- Em caso de empate na maior média, vale o estudante que aparece primeiro.
