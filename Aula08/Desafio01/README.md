# Aula 08 - Desafio 01

## Objetivo

Praticar **matrizes** combinadas com **vetores de strings** para deixar a saída mais legível.

## Descrição da solução

O programa usa os vetores de nomes `{"café", "coxinha", "bolo"}` e `{"seg", "ter", "qua"}` e uma matriz 3 x 3 de vendas. Pede a quantidade vendida de cada produto em cada dia, exibe o total por produto e o total geral de unidades.

## Como compilar e executar

```bash
gcc main.c -o programa -Wall -Wextra
./programa
```

## Observações importantes

- Os nomes dos produtos e dos dias são exibidos nas mensagens, em vez de números.
