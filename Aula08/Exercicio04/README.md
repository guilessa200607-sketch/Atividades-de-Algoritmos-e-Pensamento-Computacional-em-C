# Aula 08 - Exercício 04

## Objetivo

Praticar **matrizes** (vetores bidimensionais) e a soma por linha.

## Descrição da solução

O programa usa uma matriz 3 x 4 (3 produtos e 4 dias) e lê a quantidade vendida de cada produto em cada dia. Em seguida soma cada linha, exibindo o total vendido por produto, e acumula o total geral de unidades vendidas.

## Como compilar e executar

```bash
gcc main.c -o programa -Wall -Wextra
./programa
```

## Observações importantes

- As linhas da matriz representam os produtos e as colunas representam os dias.
