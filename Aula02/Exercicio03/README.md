# Aula 02 - Exercício 03

## Objetivo

Praticar **conversão de unidades** com números reais.

## Descrição da solução

O programa lê a quantidade de semanas de gestação, converte para dias (`semanas * 7`) e depois para meses aproximados (`dias / 30`), exibindo o resultado com duas casas decimais.

## Como compilar e executar

```bash
gcc main.c -o programa -Wall -Wextra
./programa
```

## Observações importantes

- O mês é considerado com 30 dias, por isso o resultado é aproximado.
