# Aula 02 - Exercício 04

## Objetivo

Praticar **fórmulas** e conversão entre mililitros e litros.

## Descrição da solução

O programa lê a massa corporal (kg) e calcula a quantidade de água recomendada por dia: 35 mL por quilo (`massa * 35`), convertida para litros (`/ 1000`).

## Como compilar e executar

```bash
gcc main.c -o programa -Wall -Wextra
./programa
```

## Observações importantes

- O valor de 35 mL por kg está fixo no código.
