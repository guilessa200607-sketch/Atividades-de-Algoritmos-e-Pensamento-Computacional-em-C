# Aula 02 - Exercício 02

## Objetivo

Praticar **fórmulas** com números reais: perímetro e área de um retângulo.

## Descrição da solução

O programa lê o comprimento e a largura de um jardim retangular (em metros) e calcula o perímetro (`2 * (comprimento + largura)`) e a área (`comprimento * largura`), exibindo os dois resultados.

## Como compilar e executar

```bash
gcc main.c -o programa -Wall -Wextra
./programa
```

## Observações importantes

- Correções feitas em relação ao rascunho original: a mensagem do perímetro dizia "cumprimento" (agora "perímetro") e a palavra "cumprimento" foi corrigida para "comprimento" no código e nos textos.
