# Aula 02 - Exercício 05

## Objetivo

Praticar **leitura de dados** e o cálculo da média aritmética.

## Descrição da solução

O programa lê duas notas e calcula e exibe a média aritmética delas, `(nota1 + nota2) / 2`, com duas casas decimais.

## Como compilar e executar

```bash
gcc main.c -o programa -Wall -Wextra
./programa
```

## Observações importantes

- As notas usam **ponto** como separador decimal na digitação.
